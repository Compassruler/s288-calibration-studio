# Windows解压即用版

`v0.1.2`用于普通用户下载使用，无需安装Python、Conda或SolidWorks。

本地发布目录统一为`S288零位标定工具_发布版_v0.1.2`，根部仅保留`S288Studio/`和`更新内容.txt`；构建核对报告留在源码的`build/`中。

1. 将整个软件文件夹放到桌面或文档等可写位置。
2. 双击`S288Studio.exe`。保留同目录的资源和运行库，不要只移动一个EXE。
3. 首次使用先勾选顶部“模拟设备”，确认ID为`0-14`，再点“连接设备”。
4. 选一个ID，点“使能 · 保持当前位置”，输入限位内的小角度，观察反馈和模型；用“释放当前舵机”结束控制。
5. 点击右上角“使用指引”查看逐按钮操作方法。

实机使用时选择实际串口与已接入ID。串口适配器需要对应驱动，电脑需要正常的显卡/OpenGL支持。

本次修复模型已载入时关闭窗口可能卡住的问题。

本版用ExPos输出编码器保存软件零位，已有ExPos记录可直接使用，无需仅因升级重标。原零位、限位、Kp/Kd及模型绑定保留。释放后可以手动摆动；再次使能或回零时，软件按当时反馈建立本次控制对应，不会因正常手掰报告基准失效。连接本身不会自动运动，也不会把当前姿态改为0°。

3D默认查看“实际反馈”。已标定ID在项目零位支架设计姿态上叠加ExPos相对角度，软件0°对应支架设计零位，而非原CAD保存姿态；标签显示相对支架的角度。此调整不改原CAD、机械零位或控制参数。“视角复位”只调整相机。临时对齐可用“恢复软件零位显示”撤回；断开、重连、加载配置或重录对应ID后清除，不写文件。

支架参考是14个训练关节的q=0，不是站立HOME；嘴部第15关节保留原CAD嘴部参考姿态，闭合位置须独立核对。显示参考核对不等于实物或嘴部闭合已验收。

新记录零位时，用支架固定姿态，再点“记录全部零位并保存”，一次记录本次连接的全部ID。回零以ExPos实际偏差不超过5°且稳定为到位条件。

长行程回零起步与结束各用约0.6秒平缓加减速，短行程自动缩短加减速段并降低峰值速度；“回零／限速”仍是目标速度上限，总时长稍长。手动模式、零位、限位和Kp/Kd保留；实际平稳程度取决于机构、负载和增益。

回零超时日志会分列“控制位置跟踪差”和“输出距零”，用于排查内部位置跟踪与输出残差；本版未加入自动末端补偿。

ExPos是单圈参考，拆装或更换舵机后仍须核对机械基准。当前未完成整机真机验收；控制中掉电或通信、状态异常时须停止检查并重新连接，不会自动继续旧目标。

通用构建仅带`configs/examples/`空白示例，首次保存后在同目录`configs/`生成本机零位、绑定与主题；模拟和实机分别保存。个人升级包则保留已有本机参数，仅供本机使用，不能直接用于公开分发。

升级时保留当前`configs/`中的零位和控制参数，并核对新版载入的是这份配置。

GitHub仓库只保存源码、资源与空白示例。通用软件必须从源码全新构建，不能上传已经带入本机参数的个人升级目录。具体范围见源码中的`docs/PUBLISH.md`。

## 开发者重新打包

在Windows构建环境中安装`requirements-build.txt`，然后运行：

```powershell
python tools/build_windows.py --output build/portable-v0.1.2-current
```

输出在`build/portable-v0.1.2-current/dist/S288Studio/`。打包前后应检查模拟、三维、配置保存与退出，并保留`LICENSE`、模型来源说明及`licenses/`中的运行库声明。
