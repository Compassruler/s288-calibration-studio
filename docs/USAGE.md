# 使用说明与代码结构

Windows桌面工具，支持同一串口下的ID 0–14。`v0.1.2`采用输出编码器零位，回零使用平缓加减速，保留原机械结构显示模型。

## 启动和界面

- 双击 `模拟体验.bat`：自动连接模拟设备，不打开真实串口。
- 双击 `启动工具.bat`：进入实机模式，连接前不会使能舵机。
- 启动脚本依次查找 `S288_PYTHON`、本地 `.venv`、Windows `py -3` 和系统 `python`。`S288_PYTHON`应填写解释器完整路径，不能包含命令参数。
- 软件内右上角“使用指引”提供按按钮排列的完整操作步骤。

主界面左侧选择 ID，中间查看机械模型，左右两侧分别调节和设置；反馈、软件零位和日志同时可见。模块尺寸不会随角度位数、状态文字或模型画面更新而变化；手动改变窗口大小时仍会适配。空间足够时自动使用宽屏字号和间距，还原窗口后恢复紧凑布局。右上角切换深浅主题，模型下方切换视角和半透明。以上显示操作不会发送运动命令。

板块、按钮、输入框、下拉框和状态标签使用统一圆角，角度滑块使用圆形滑钮。圆角图片按窗口和主题缓存，切换主题会复用，不增加持续动画或轮询；Tab 焦点、空格点击、输入框编辑和下拉选择仍由原生控件处理。

按钮点击后会短暂高亮，底栏显示操作提示；连接、使能和回零等操作会先显示“正在…”，再根据实际反馈更新结果。灰色按钮被点击时会提示“当前不可用”，不会执行命令。“已收到”或“目标已提交”只确认软件收到操作，实际到位仍看角度反馈和实物。连续微调只更新底栏，不重复刷日志。

## 常用操作

1. 支撑好机构，关闭占用串口的官方助手。选串口，填写本次实际接入的 ID，再点“连接设备”。单台填 `14`，多台可填 `0,2,14`，全部接入且 ID 不重复时才填 `0-14`。缺少任意所填 ID 会拒绝连接；连接过程中可点“取消连接”。
2. 左侧选 ID，在右侧填写名称、控制方向、允许角度和跟随模式，点“应用设置”。Kp、Kd 只需填写一组，再点“统一应用 Kp / Kd 并保存”，全部 ID 同时生效并保存，不用逐台重复。模型关节及模型方向也在这里设置；更改模型绑定会自动保存，其他控制参数还需点顶部“保存配置”。
3. 点“使能 · 保持当前位置”，等使能确认后，再拖滑块、微调，或在“目标 / °”输入数值并点“执行输入”（Enter 也可）。使能或记录零位正在等待反馈时，暂不切换 ID。
4. “停止并保持”取消剩余目标并保持当前实测位置；“释放当前舵机”请求零驱动力矩；左下“全部请求零力矩”操作本次连接的全部 ID。释放不等于断电，通信故障时以日志中的确认结果为准。
5. 记录零位：先全部释放，用零位支架固定好所有关节，静止约半秒，点“记录全部零位并保存”。软件对ExPos作圆周平均，全部已连接 ID稳定且正常才一次保存，跨过0／2π的采样也能正确记录；采样异常、取消或写盘失败时保留原有零位。只需重记一台时，仍可选 ID 后点“记录为0°并保存”。核对保存日志；使用支架时，先拆除绑带并取出机器人，再做小角度及方向验证。验证后释放、点“标记验证”，再保存配置。
6. 回零：先全部释放，再点“当前回零”或“全部回零”。软件按保存的参考位置平缓起步、减速返回，ExPos实测偏差不超过5°并稳定后确认到位，完成后保持；点“停止并释放”结束。全部回零要求已标定的所有 ID 都在连接列表内。
7. 清除记录：选中 ID 后点“清除当前零位”，或点“清除全部零位”，核对确认框。清除会保存到当前配置，名称、方向、限位、增益和模型绑定保留；保存失败时保留原记录。

## 角度、方向和速度

| 内容 | 含义 |
|---|---|
| 目标输入、滑块、上下限 | 单位为度，支持限位内的负值 |
| `outputPos`、`ExPos` | 单位为弧度；前者是转子累计位置换算，后者是输出端单圈编码器 |
| 未标定 ID | 显示本次连接的临时角度，连接姿态暂作 0° |
| 已标定 ID | 角度 = 控制方向 × wrap(ExPos − 保存的reference_expos)，wrap取−π到π的单圈有符号差 |
| `reference_expos` | 保存的软件零位，单台和全部记录均用ExPos圆周平均 |
| `zero_offset` | 历史兼容锚点，不决定实测角度或已标定模型的零位，也不保证等于本次转子位置均值 |
| 控制方向 | 决定正角度目标对应的真实舵机转向 |
| 模型方向 | 只改变三维显示转向，不单独驱动舵机 |
| Kp、Kd | 输出端的位置刚度和速度阻尼；协议层负责转子端换算 |

统一 Kp、Kd 在全部释放后设置，对当前配置的全部15个 ID 生效，也包括暂时未连接的 ID；“统一应用 Kp / Kd 并保存”写盘成功后才更新参数。修改增益后点普通“应用设置”也会统一更新全部 ID 的内存参数，但仍需保存配置。切换 ID 不会重置这组输入。载入旧配置会保留原参数，不会自动提高增益。零位、控制方向、限位和模型绑定不受统一增益操作影响。

回零仍把精确保存的零位作为控制目标，5°仅用于软件到位判断；它不会修正机械偏差、重写零位或提高真实精度。“标记验证”仍是完成实物检查后的人工确认。

手动“直接跟随”立即发送最终位置，不使用限速值；“限速移动”按“回零／限速 °/s”逐步改变目标。例如手动限速设为15°/s，目标从0°到30°约用2秒完成下发。

回零使用独立的S形加减速：长行程起步与结束各约0.6秒，中间保持恒速；短行程自动缩短加减速段并降低峰值速度，最终目标仍是精确零位。“回零／限速 °/s”仍为目标速度上限；起停更平缓，因此比单纯按距离除以速度计算的时长稍长。它不会改变手动模式、ExPos零位、限位、±5°验收或Kp/Kd。

这些设置控制目标变化，并非硬件实际转速上限；协议的期望角速度和前馈力矩仍为0。实际平稳程度还受机构、负载和增益影响。

软件零位不会写入舵机固件，采用部署标定例程保存ExPos的方法。已有 `reference_expos` 会原样使用，无需仅因升级重新标定；连接本身不驱动舵机，也不会把当前姿态当成0°。缺少ExPos零位的旧记录需要重新记录，不能直接把旧转子位置当成输出编码器零位。

每次使能或开始回零时，软件读取当时的 `outputPos` 和 `ExPos`，建立这一次位置控制的对应关系；该关系保持到释放，控制中不逐帧修正。实测角度、限位检查和回零±5°验收始终以ExPos为准。释放后正常手动摆动不会触发“基准失效”，再次使能会按新姿态建立对应。

ExPos为单圈参考，不记录整圈次数。拆装、跑齿或更换舵机后须复核机械参考。当前未完成整机真机验收；控制期间舵机断电、通信或状态异常时，仍须停止检查并重新连接，不会自动继续旧目标。

角度限位须严格位于−180°与180°之间；单圈180°分界无法区分两侧方向，会拒绝控制并提示检查姿态。

## 模型与绑定

中央模型保留原装配显示快照的239个组件、49个网格和15条关节链。模型网格、原装配位置、轴心与转轴保持不变；显示资产增加静态姿态偏移，使默认参考采用项目零位支架设计姿态，而非原CAD保存的装配姿态。M1–M15为装配编号，不等于电气ID，需按实物逐个绑定。

选择模型关节只预览高亮；点“应用设置”才提交绑定。只有当前舵机本体高亮，下游零件仍按父子关系随动。已标定ID按“支架设计姿态偏移＋模型方向 × wrap(ExPos−保存的reference_expos)”渲染。软件角度为0°时显示支架设计零位姿态，界面标签仍显示相对支架的角度，不把内部静态偏移当作实测角度。此显示调整不会改写原CAD、现有绑定或机械零位、方向、限位、Kp/Kd。

模型默认使用“实际反馈”；仍可切换“目标预览”查看请求目标，两者使用同一设计姿态偏移，目标预览不表示已经到位。“视角复位”只恢复相机视角，不改变关节姿态或机械零位。

参考来自项目原始零位支架设计数据：14个训练关节的q=0，与站立HOME及“看起来伸直”不同。第15个嘴部关节保留原CAD嘴部参考姿态，不属于该14关节支架零位模型；闭嘴机械位置和电子零位仍需独立核对。此处验证的是显示资产与支架设计参考，未据此宣称实物装配、承载或嘴部闭合已验收。

已标定ID执行“临时对齐模型参考”时，只设置本连接的临时显示参考，状态会明确提示；点“恢复软件零位显示”可撤回。断开、重新连接、加载配置或重新记录该ID的零位时会清除临时参考，不写绑定或零位文件。未标定ID保留原来的“对齐模型参考”及独立手工参考保存方式；只有旧raw零位而缺少ExPos的记录不会用于推断模型姿态。

未绑定、尚无有效参考或反馈异常时不会推断实机姿态。模拟示例映射只用于体验，不能当作真实ID表；模拟总线也不代表S288/BAM动力学。

## 与强化学习部署例程配合

主界面右侧增加“部署名 / 序号”（左框为英文关节名，右框为1–15策略动作序号）、“导入部署映射”和“导出部署标定”。这些定义独立于 CAD 显示绑定。导入和导出只处理配置文件，不访问串口或运行策略。

1. 按自己的训练 XML 设置英文部署关节名，策略序号按训练动作数组从 1 编号。逐台点“应用设置”，最后“保存配置”。名称和序号不能重复，修改占用项时先清空旧项。
2. 已有布局文件时点“导入部署映射”，选择含 `joint_to_motor_id` 和 `policy_joint_order` 的 JSON，例如例程 `configs/reference_14dof.json`。导入前会确认，零位、方向、限位、增益和 CAD 绑定均保留。参考14布局会清空 ID14 的部署映射，保留其零位；不能据此猜测实际接线。
3. 记录参与关节的零位、核验方向并“标记验证”。软件零位应对应训练模型的 `q=0`，不能把任意摆放姿态或站立 HOME 自动当成此参考。
4. 全部释放后点“导出部署标定”，按提示确认参考姿态和导出范围，另存独立 `.json`。模拟数据、映射不完整、缺 ExPos 或尚未验证的记录会被拒绝；原软件零位文件和训练布局不会被覆盖。

导出采用例程的 `format_version/robot/reference_pose/joints` 标定字段。`encoder_home_rad` 来自保存的 `reference_expos`，不是 `zero_offset`；方向使用控制方向，不使用 CAD 显示方向。额外 `deployment` 信息记录关节/动作顺序、弧度限位、波特率、减速比及标定增益换算。

- **参考14关节**：名称、ID 和策略顺序必须与原例程完全一致；ID14排除情况会明确提示。生成字段可由原例程标定加载器读取。
- **自定义15关节**：保留 ID 0–14，策略序号必须完整为 1–15；标记 `requires_runtime_adaptation`。原例程固定14关节，需要同步适配部署代码、训练模型和策略后使用，导出不会修改它。
- **波特率**：顶部提供 `6000000/4000000`，默认6 Mbps，连接后锁定。选择只改变电脑串口设置，不会给电机写入波特率；4 Mbps需电机、适配器和部署端一起匹配。启动时默认仍为6 Mbps。
- **增益**：保持本工具输出端物理单位；导出记录 `Kp_sdk=Kp/RATIO²`、`Kd_sdk=Kd/RATIO²`，并注明原工具编码使用 `round`。这些是标定参数，不能自动替换训练配套增益。保留原减速比 `70070/243`，同时记录例程参考值 `288.35`，不悄悄修改控制协议。

本次修改仅调整标定工具的ExPos零位和控制对应，不修改原例程的策略观测、ONNX或IMU流程，也不把任何默认高增益写入现有设置。14关节导出保持原标定字段兼容；15关节仍需适配部署程序。使用指引第06节给出了逐按钮步骤。

## 软件配置文件

| 文件 | 内容 |
|---|---|
| `configs/calibration.json` | 实机的软件零位和控制设置 |
| `configs/demo_calibration.json` | 模拟模式设置 |
| `configs/model_bindings.json` | 实机模型映射和显示参考 |
| `configs/demo_model_bindings.json` | 模拟模型映射和显示参考 |
| `configs/appearance.json` | 深浅主题偏好 |

模拟与实机文件不能混用。“记录为0°并保存”“记录全部零位并保存”和清除零位会立即保存到当前配置。单台记录保存失败时保留内存记录并明确提示未保存，可点“保存配置”重试或另存；全部记录则在全部采样通过、写盘成功后才统一替换原零位，失败不会留下部分新零位。未连接 ID 的零位保留。其他控制设置点“应用设置”后仍需“保存配置”。模型绑定单独自动保存，写盘成功后才更新内存；失败时保留原绑定和参考，检查路径权限后手动重试。

保存零位配置时会先校验，再写临时文件并替换正式文件，上一版保留为同名 `.bak`。“恢复备份”只载入上一版，核对后再保存。使用 `--config 路径` 可指定其他配置；不指定时启动对应模式的默认配置。

升级直接保留原配置中的ExPos零位、控制方向、限位、Kp/Kd和模型绑定；打开软件或连接设备不会改写这些参数。

明确重新记录零位时，历史兼容锚点仍按新旧ExPos零位之差同步更新；第一次标定才用当时的转子位置建立该锚点。已标定模型直接使用新的ExPos零位，不依赖该兼容锚点。

## 故障处理

通信异常、设备状态异常、活动反馈过期或实测越限时，会停止主动控制、请求零力矩并锁止；检查实物及日志后再断开重连。软件限位保护与电机内部保护并存；活动限位预留2°的小幅超调容差，目标仍严格受原限位约束。不会自动扩大目标范围或增加增益；无效ExPos反馈会被拒绝。

回零未到位与通信故障分开处理：到位超时会报告实际偏差并请求全部释放；所有释放都获健康反馈时保留连接，等待人工检查，不自动重试。释放未确认或设备异常仍锁止。

超时日志中的“控制位置跟踪差”是当前控制目标减去实测位置，符号沿转子控制方向；“输出距零”是ExPos相对保存零位、按关节方向计算的实际偏差。两项分开显示，便于判断内部位置跟踪与输出残差；本版未加入自动末端补偿，不会据此改写零位或自动加大目标。

只有模型动时，核对是否处于模拟模式或“目标预览”；以实际角度、下方反馈和实物为准。电机异响、异常跳动或无法通信的原因，不能仅靠本软件的离线测试确定。

## 以后如何修改代码

| 文件 | 负责内容 | 常用修改入口 |
|---|---|---|
| `app.py` | 主界面操作与异步事件 | 按钮操作、滑块目标合并、零位保存流程、界面状态 |
| `controller.py` | 唯一的总线通信线程 | 连接、使能、保持、释放、回零；`FEEDBACK_MAX_AGE_S`、`ACTIVE_LIMIT_MARGIN_DEG` 是活动保护参数 |
| `zero_coordinates.py` | ExPos角度与圆周采样 | 单圈有符号差、圆周平均；不访问设备 |
| `homing_motion.py` | 平滑回零目标轨迹 | 长短行程加减速、峰值速度与精确终点；不改变手动模式 |
| `protocol.py` | S288 报文与单位换算 | `build_packet`、`parse_feedback`、CRC；模拟总线也在此 |
| `config.py` | 零位配置与参数验证 | `default_profiles` 的默认值、`validate_profile` 的允许范围 |
| `deployment.py` | 部署布局导入与标定导出 | 关节/动作顺序校验、ExPos零位转换、标定增益单位说明、独立文件保存；不访问硬件 |
| `ui.py` | 主界面布局、主题与按钮反馈 | `PALETTES`、`build_ui`、`ResponsiveLayout`、`FeedbackButton`；宽屏和高亮时间参数集中在顶部 |
| `rounded_theme.py` | 圆角绘制与图片缓存 | `CARD_RADIUS`、`CONTROL_RADIUS` 调整圆角；`TILE_SIZE` 保持较大以避免全屏平铺开销；不处理通信或控制 |
| `robot_view.py` | 只读的机械结构联动 | 显示参数、相机、绑定提交、父子位姿；不访问控制线程 |
| `guide.py` | 软件内使用指引 | `SECTIONS` 的中文说明 |
| `tests/` | 离线验证 | 模拟、串口替身、文件失败及界面状态测试 |

修改时保持这些边界：

- 控件和文件对话框在主线程运行；串口只能由 `Controller` 访问，后台模型加载不能访问 Tk。
- 角度换算只在明确的边界做：界面用度，保存及控制内部用弧度，协议层再换成转子单位。
- 清除零位和修改模型绑定先写盘、后提交内存。记录新零位自动保存失败时，保留该次内存记录并标记未保存，供手动另存；不能把它显示为保存成功。
- 停止、释放、断开和关闭必须取消尚未执行的旧目标；不能为简化代码删除这些约束。
- 改默认值不会覆盖已有配置。调整参数允许范围时同时核对界面提示、配置验证和通信控制，不要只放大输入范围。
