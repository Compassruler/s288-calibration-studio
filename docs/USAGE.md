# 使用说明与代码结构

Windows桌面工具，支持同一串口下的ID 0–14。公开版保留原机械结构显示模型，用于绑定与关节联动。

## 启动和界面

- 双击 `模拟体验.bat`：自动连接模拟设备，不打开真实串口。
- 双击 `启动工具.bat`：进入实机模式，连接前不会使能舵机。
- 启动脚本依次查找 `S288_PYTHON`、本地 `.venv`、Windows `py -3` 和系统 `python`。`S288_PYTHON`应填写解释器完整路径，不能包含命令参数。
- 软件内右上角“使用指引”提供按按钮排列的完整操作步骤。

主界面左侧选择 ID，中间查看机械模型，左右两侧分别调节和设置；反馈、软件零位和日志同时可见。空间足够时自动使用宽屏字号和间距，还原窗口后恢复紧凑布局。右上角切换深浅主题，模型下方切换视角和半透明。以上显示操作不会发送运动命令。

板块、按钮、输入框、下拉框和状态标签使用统一圆角，角度滑块使用圆形滑钮。圆角图片按窗口和主题缓存，切换主题会复用，不增加持续动画或轮询；Tab 焦点、空格点击、输入框编辑和下拉选择仍由原生控件处理。

按钮点击后会短暂高亮，底栏显示操作提示；连接、使能和回零等操作会先显示“正在…”，再根据实际反馈更新结果。灰色按钮被点击时会提示“当前不可用”，不会执行命令。“已收到”或“目标已提交”只确认软件收到操作，实际到位仍看角度反馈和实物。连续微调只更新底栏，不重复刷日志。

## 常用操作

1. 支撑好机构，关闭占用串口的官方助手。选串口，填写本次实际接入的 ID，再点“连接设备”。单台填 `14`，多台可填 `0,2,14`，全部接入且 ID 不重复时才填 `0-14`。缺少任意所填 ID 会拒绝连接；连接过程中可点“取消连接”。
2. 左侧选 ID，在右侧填写名称、控制方向、允许角度、Kp、Kd 和跟随模式，点“应用设置”。模型关节及模型方向也在这里设置；更改模型绑定会自动保存，控制参数还需点顶部“保存配置”。
3. 点“使能 · 保持当前位置”，等使能确认后，再拖滑块、微调，或在“目标 / °”输入数值并点“执行输入”（Enter 也可）。使能或记录零位正在等待反馈时，暂不切换 ID。
4. “停止并保持”取消剩余目标并保持当前实测位置；“释放当前舵机”请求零驱动力矩；左下“全部请求零力矩”操作本次连接的全部 ID。释放不等于断电，通信故障时以日志中的确认结果为准。
5. 记录零位：先全部释放并支撑机构，手动摆到所需姿态，静止约半秒，点“记录为0°并保存”。核对保存日志，逐个 ID 重复；完成小角度验证后，释放、点“标记验证”，再保存配置。
6. 回零：先全部释放，再点“当前回零”或“全部回零”。软件按保存的参考位置限速返回并确认实测到位，完成后保持；点“停止并释放”结束。全部回零要求已标定的所有 ID 都在连接列表内。
7. 清除记录：选中 ID 后点“清除当前零位”，或点“清除全部零位”，核对确认框。清除会保存到当前配置，名称、方向、限位、增益和模型绑定保留；保存失败时保留原记录。

## 角度、方向和速度

| 内容 | 含义 |
|---|---|
| 目标输入、滑块、上下限 | 单位为度，支持限位内的负值 |
| `outputPos`、`ExPos`、保存的零位 | 单位为弧度；两种位置参考不能直接互换 |
| 未标定 ID | 显示本次连接的临时角度，连接姿态暂作 0° |
| 已标定 ID | 角度 = 控制方向 ×（反馈位置 − 保存的零位） |
| 控制方向 | 决定正角度目标对应的真实舵机转向 |
| 模型方向 | 只改变三维显示转向，不单独驱动舵机 |
| Kp、Kd | 输出端的位置刚度和速度阻尼；协议层负责转子端换算 |

“直接跟随”立即发送最终位置，手动调节不使用限速值。“限速移动”按“回零／限速 °/s”逐步改变目标；回零始终使用该值。例如设为 15°/s，目标从 0°到 30°约用 2 秒完成下发，实际到位取决于舵机响应。这里控制的是目标变化率，并非硬件实际转速上限；协议的期望角速度和前馈力矩保持为 0。

软件零位不会写入舵机固件。断电重启、拆装、跑齿或更换舵机后须复核机械参考；当前版本不保证断电后的绝对零位自动恢复。`ExPos` 记录用于复核，不能据此直接宣称已完成恢复验证。

## 模型与绑定

中央模型保留原装配显示快照的239个组件、49个网格和15条关节链。仅清理了本地来源路径及不参与显示的来源信息；网格、转轴和父子关系保持不变。M1–M15为装配编号，不等于电气ID，需按实物逐个绑定。

选择模型关节只预览高亮；点“应用设置”才提交绑定。只有当前舵机本体高亮，下游零件仍按父子关系随动。已有参考下只修改模型方向会保留参考点；明确执行“对齐模型参考”才重新记录显示起点。绑定、参考和软件零位彼此独立。

“目标预览”显示请求目标，“实际反馈”显示实测动作；前者不表示舵机已经到位。未绑定、尚无有效参考或反馈异常时不会推断实机姿态。模拟示例映射只用于体验，不能当作真实 ID 表；模拟总线也不代表 S288/BAM 动力学。

## 与强化学习部署例程配合

主界面右侧增加“部署名 / 序号”（左框为英文关节名，右框为1–15策略动作序号）、“导入部署映射”和“导出部署标定”。这些定义独立于 CAD 显示绑定。导入和导出只处理配置文件，不访问串口或运行策略。

1. 按自己的训练 XML 设置英文部署关节名，策略序号按训练动作数组从 1 编号。逐台点“应用设置”，最后“保存配置”。名称和序号不能重复，修改占用项时先清空旧项。
2. 已有布局文件时点“导入部署映射”，选择含 `joint_to_motor_id` 和 `policy_joint_order` 的 JSON，例如例程 `configs/reference_14dof.json`。导入前会确认，零位、方向、限位、增益和 CAD 绑定均保留。参考14布局会清空 ID14 的部署映射，保留其零位；不能据此猜测实际接线。
3. 记录参与关节的零位、核验方向并“标记验证”。软件零位应对应训练模型的 `q=0`，不能把任意摆放姿态或站立 HOME 自动当成此参考。
4. 全部释放后点“导出部署标定”，按提示确认参考姿态和导出范围，另存独立 `.json`。模拟数据、映射不完整、缺 ExPos 或尚未验证的记录会被拒绝；原软件零位文件和训练布局不会被覆盖。

导出采用例程的 `format_version/robot/reference_pose/joints` 标定字段。`encoder_home_rad` 来自保存的 `reference_expos`，不是 `zero_offset`；方向使用控制方向，不使用 CAD 显示方向。额外 `deployment` 信息记录关节/动作顺序、弧度限位、波特率、减速比及标定增益换算。

- **参考14关节**：名称、ID 和策略顺序必须与原例程完全一致；ID14排除情况会明确提示。生成字段可由原例程标定加载器读取。
- **自定义15关节**：保留 ID 0–14，策略序号必须完整为 1–15；标记 `requires_runtime_adaptation`。原例程固定14关节，需要同步适配部署代码、训练模型和策略后使用，导出不会修改它。
- **波特率**：顶部提供 `6000000/4000000`，默认6 Mbps，连接后锁定。选择只改变电脑串口设置，不会给电机写入波特率；4 Mbps需电机、适配器和部署端一起匹配。启动时默认仍为6 Mbps。
- **增益**：保持本工具输出端物理单位；导出记录 `Kp_sdk=Kp/RATIO²`、`Kd_sdk=Kd/RATIO²`，并注明原工具编码使用 `round`。这些是标定参数，不能自动替换训练配套增益。保留原减速比 `70070/243`，同时记录例程参考值 `288.35`，不悄悄修改控制协议。

本次适配不加载 ONNX 或 IMU，不把任何默认高增益写入现有设置，也不保证断电后的机械零位恢复。使用指引第06节给出了逐按钮步骤。

## 软件配置文件

| 文件 | 内容 |
|---|---|
| `configs/calibration.json` | 实机的软件零位和控制设置 |
| `configs/demo_calibration.json` | 模拟模式设置 |
| `configs/model_bindings.json` | 实机模型映射和显示参考 |
| `configs/demo_model_bindings.json` | 模拟模型映射和显示参考 |
| `configs/appearance.json` | 深浅主题偏好 |

模拟与实机文件不能混用。“记录为0°并保存”和清除零位会立即保存到当前配置；记录新零位保存失败时保留内存记录并明确提示未保存，可点“保存配置”重试或另存。其他控制设置点“应用设置”后仍需“保存配置”。模型绑定单独自动保存，写盘成功后才更新内存；失败时保留原绑定和参考，检查路径权限后手动重试。

保存零位配置时会先校验，再写临时文件并替换正式文件，上一版保留为同名 `.bak`。“恢复备份”只载入上一版，核对后再保存。使用 `--config 路径` 可指定其他配置；不指定时启动对应模式的默认配置。

## 故障处理

通信异常、设备状态异常、活动反馈过期或实测越限时，会停止主动控制、请求零力矩并锁止；检查实物及日志后再断开重连。软件限位保护与电机内部保护并存；活动限位预留2°的小幅超调容差，目标仍严格受原限位约束。不会自动扩大目标范围、增加增益或把异常角度取模成正常读数。

回零未到位与通信故障分开处理：到位超时会报告实际偏差并请求全部释放；所有释放都获健康反馈时保留连接，等待人工检查，不自动重试。释放未确认或设备异常仍锁止。

只有模型动时，核对是否处于模拟模式或“目标预览”；以实际角度、下方反馈和实物为准。电机异响、异常跳动或无法通信的原因，不能仅靠本软件的离线测试确定。

## 以后如何修改代码

| 文件 | 负责内容 | 常用修改入口 |
|---|---|---|
| `app.py` | 主界面操作与异步事件 | 按钮操作、滑块目标合并、零位保存流程、界面状态 |
| `controller.py` | 唯一的总线通信线程 | 连接、使能、保持、释放、回零；`FEEDBACK_MAX_AGE_S`、`ACTIVE_LIMIT_MARGIN_DEG` 是活动保护参数 |
| `protocol.py` | S288 报文与单位换算 | `build_packet`、`parse_feedback`、CRC；模拟总线也在此 |
| `config.py` | 零位配置与参数验证 | `default_profiles` 的默认值、`validate_profile` 的允许范围 |
| `deployment.py` | 部署布局导入与标定导出 | 关节/动作顺序校验、ExPos零位转换、标定增益单位说明、独立文件保存；不访问硬件 |
| `ui.py` | 主界面布局、主题与按钮反馈 | `PALETTES`、`build_ui`、`ResponsiveLayout`、`FeedbackButton`；宽屏和高亮时间参数集中在顶部 |
| `rounded_theme.py` | 圆角绘制与图片缓存 | `CARD_RADIUS`、`CONTROL_RADIUS` 调整圆角；`TILE_SIZE` 保持较大以避免全屏平铺开销；不处理通信或控制 |
| `robot_view.py` | 只读的机械结构联动 | 显示参数、相机、绑定提交、父子位姿；不访问控制线程 |
| `guide.py` | 软件内使用指引 | `SECTIONS` 的中文说明 |
| `tests/` | 离线验证 | 模拟、串口替身、文件失败及界面状态测试 |

修改时保持这些边界：

- 控件和文件对话框在主线程运行；串口只能由 `Controller` 访问，后台模型加载不能访问 Tk。
- 角度换算只在明确的边界做：界面用度，保存及控制内部用弧度，协议层再换成转子单位。
- 清除零位和修改模型绑定先写盘、后提交内存。记录新零位自动保存失败时，保留该次内存记录并标记未保存，供手动另存；不能把它显示为保存成功。
- 停止、释放、断开和关闭必须取消尚未执行的旧目标；不能为简化代码删除这些约束。
- 改默认值不会覆盖已有配置。调整参数允许范围时同时核对界面提示、配置验证和通信控制，不要只放大输入范围。

在本工具文件夹运行检查：

```powershell
python -B tests/run_checks.py
```

测试使用模拟总线、串口替身和临时文件，不打开真实串口。测试启动器在主线程回收 Tk 测试对象，避免后台线程清理旧测试窗口；应用本身不修改垃圾回收设置。离线通过不等于已验证每台真实舵机运动或断电恢复。
